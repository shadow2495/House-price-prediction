# 🏠 House Price Prediction System

End-to-end ML pipeline for predicting Ames housing sale prices.
Covers EDA → Feature Engineering → Model Training (with MLflow) → FastAPI backend → Streamlit dashboard → Docker deployment.

## Dataset
Ames Housing Dataset — [Kaggle: House Prices - Advanced Regression Techniques](https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques/data)

Download `train.csv` and `test.csv` → place both in `data/`

## Project Structure
```
house-price-prediction/
├── data/
│   ├── train.csv
│   └── test.csv
├── models/               ← saved after training
│   ├── best_model.pkl
│   ├── scaler.pkl
│   └── feature_names.pkl
├── plots/                ← auto-generated by train.py
├── src/
│   ├── train.py          ← full ML pipeline + MLflow
│   └── api.py            ← FastAPI backend
├── app.py                ← Streamlit frontend
├── Dockerfile
├── docker-compose.yml
└── requirements.txt
```

## Quick Start

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Place train.csv + test.csv in data/
mkdir -p data plots models

# 3. Train models (generates plots + saves model)
python src/train.py

# 4. Start FastAPI backend
uvicorn src.api:app --reload --port 8000
# API docs → http://localhost:8000/docs

# 5. Start Streamlit dashboard (new terminal)
streamlit run app.py
# Dashboard → http://localhost:8501
```

## Docker (optional)
```bash
# Build + run both services
docker-compose up --build

# API  → http://localhost:8000/docs
# App  → http://localhost:8501
```

## Key Results
- Best model: XGBoost (R² ≈ 0.91, CV-RMSE ≈ 0.121 on log scale)
- Engineered 10+ new features: TotalSF, HouseAge, TotalBathrooms, HasGarage, etc.
- Tracked 10+ MLflow experiments across 6 model types
- FastAPI inference latency < 120ms per request
